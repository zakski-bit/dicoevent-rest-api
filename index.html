🏛️ Arsitektur & Spesifikasi Kriteria

Dibangun memenuhi standar industri backend engineering modern.

📦

Object Storage (MinIO SDK)

Unggah poster acara dengan validasi MIME gambar dan ukuran maks 500 kB. Metadata disimpan di PostgreSQL dan file di-stream via S3-compatible API.

⚡

High-Speed Cache (Redis)

Meningkatkan throughput dengan header X-Data-Source (cache/database). Dilengkapi cache invalidation otomatis saat event diubah.

⏰

Async Workers (Celery)

Pengiriman email pengingat acara otomatis H-2 jam sebelum event dimulai tanpa memblokir request pengguna (non-blocking thread queue).

📊

Structured Logging (Loguru)

Observability terstruktur dengan format timestamp | level | message, pemisahan file info dan error, serta rotasi log harian.
